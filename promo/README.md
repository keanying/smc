# CloudSense 云听 · 宣传片

74 秒、1920×1080、30fps、横屏 16:9。画面全部是代码绘制的示意界面（不使用真实系统截图），配乐也是纯代码合成，不含第三方素材。

## 分镜

| 时间 | 段落 | 内容 |
| :--- | :--- | :--- |
| 0–6s | 开场 | 光线展开 → Logo → CloudSense 字符解码 → 「景区社媒舆情采集系统」 |
| 6–12s | 痛点 | 七个平台散落、评论气泡乱飞：各自翻、各自导、口径不一；人工标注跟不上 |
| 12–18s | 汇聚 | 七个平台绕「景区」核心旋转，数据流汇入：统一采集、统一入库 |
| 18–26s | 01 总览 | 3D 仪表盘：KPI 计数、14 天趋势、平台分布、实时动态 |
| 26–34s | 02 调度 | 四种调度切换、cron 输入与下次执行预览、24h 时钟、固定间隔时间轴 |
| 34–42s | 03 账号池 | 最久未用优先轮换、配额与冷却、FIFO 排队、账号失效告警 |
| 42–52s | 04 AI 标注 | 评论流穿过 AI 扫描线被打上情感/维度/关键词；情感环形图、热词、复核闭环 |
| 52–60s | 05 集群 | 主机派任务、节点写库；从机 C 掉线，任务由 B 自动接手 |
| 60–66s | 快剪 | 实时日志 / 推流登录 / 数据导出 / 飞书告警，每 1.5 秒一切 |
| 66–74s | 收尾 | Logo + Slogan「让景区的每一条声音，都被听见」+ 技术栈 + 许可声明 |

配乐 120 BPM（一小节 2 秒），A 小调 Am–F–C–G。每个转场都落在小节线或拍点上；
2s / 12s / 42s / 60s / 66s 是重点节点，用冲击音 + 前置上扬 + 军鼓滚奏强调，其余转场用镲片 + 呼啸。

## 重新出片

需要 Python（playwright、numpy、scipy）、Chromium、ffmpeg、Noto Sans CJK 和 JetBrains Mono 字体。

```bash
bash promo/video/build.sh
```

- `video/promo.html`：画面。`render(t)` 把画面摆到第 t 秒；直接用浏览器打开会循环实时预览。
- `video/render.py`：逐帧截图交给 ffmpeg。`python render.py stills 3 15 22` 只出静帧用于检查。
- `video/music.py`：合成配乐，转场时间点 `CUTS` 要和 `promo.html` 里的保持一致。
- 产物在 `video/out/`（不入库）。
