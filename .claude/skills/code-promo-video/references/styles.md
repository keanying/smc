# 风格、配乐与版式

## 主题 × 配乐情绪

| 题材 | `theme` | `mood` | BPM | 转场 `transition` |
| :--- | :--- | :--- | :--- | :--- |
| 软件、数据、AI、开发者工具、互联网产品 | `tech` | `tech` | 120 | `flash` |
| 餐饮、茶饮、零售、生活方式、旅游、亲子 | `fresh` | `bright` | 116–120 | `soft` |
| 企业介绍、B2B、SaaS、金融、咨询 | `business` | `corporate` | 110–120 | `soft` |
| 品牌故事、公益、纪念、人物 | `fresh` 或 `business` | `warm` | 88–96 | `soft` |
| 发布会、大事件、国风文创、节庆 | `guochao`（国风）/ `tech`（发布会） | `epic` | 96–104 | `flash` |

用户说“科技感”“炫酷”→ tech；“清新”“小清新”“治愈”→ fresh + bright；“高级”“简约”“商务”→ business；
“国潮”“中国风”“喜庆”→ guochao。拿不准就按题材选。

BPM 不是 120 时，拍长 = 60/BPM，小节 = 4 拍。先定 BPM 再定转场时间：
例如 116 BPM 一小节 ≈ 2.069 秒，场景边界用小节的整数倍（2.069、4.138……），保留两位小数即可。
最省事的做法是继续用 120 BPM，只换情绪——绝大多数题材都合适。

## 主题定制

主题都是 `themes.css` 里的一组 token。要贴合用户品牌色时，在页面 `<style>` 里覆盖：
```css
:root[data-theme="fresh"] { --accent: #e4572e; --accent2: #f3a712; --title: linear-gradient(100deg,#5a1d0a,#e4572e) }
```
浅色主题（fresh / business）的面板是白底，正文用 `var(--ink)`；深色主题（tech / guochao）面板是深色玻璃。
`.ttl` 用渐变文字，在浅色主题上已经是深色渐变，不用另改。

## 版式

**横屏 16:9（1920×1080）**：经典“左文案右面板”——文字栏 `left:110px; width:520px`，面板 `left:700px; width:1120px`。
标题 72px，副标题 26–28px，要点 24–25px，正文最小 16px（再小在手机上看不清）。

**竖屏 9:16（1080×1920）**：上下分区。
- 上 1/3（y 160–700）：kicker + 标题 + 一句副标题，水平居中，左右留 80px。
- 中间（y 760–1500）：示意面板，宽 920，居中 `left:80px`。
- 底部（y 1560–1760）：要点或行动号召。y > 1780 和 y < 120 是平台 UI 遮挡区，不放关键信息。
- 标题可到 88–96px，正文最小 22px；一屏只放一组信息，宁可多切一个场景。
- 背景透视网格的地平线会在 0.7×高度处，竖屏时更靠下，正好托住面板。
- 现成的类：`.vcol`（顶部居中文字区，标题 92px）、`.vpanel`（宽 920 居中，配合 `.panel` 自己给 top/height）。

```html
<div class="scene" id="v1">
  <div class="vcol">
    <div class="kick" data-in=".3">01 / FRESH</div>
    <div class="ttl" data-in=".5">真果鲜切<br>一杯看得见</div>
    <div class="sub" data-in=".9">一句副标题</div>
  </div>
  <div class="panel vpanel" style="top:760px;height:720px" data-in="1.0"><span class="demo-tag">示意</span>…</div>
  <div class="abs center" style="top:1560px;font-size:30px" data-in="1.6">底部要点 / 行动号召</div>
</div>
```
- 竖屏收尾的地址 / 二维码卡片放在 y 1300–1650，离底部遮挡区留足距离。

**方形 1:1（1080×1080）**：上标题、下面板，面板宽 920；文字比横屏再精简一档。

## 文案节奏

- 每个场景的文字顺序：小标（编号 / 英文）→ 大标题 → 一句副标题 → 2–4 个要点，依次延迟 0.2–0.4 秒入场。
- 大标题写“结果”不写“功能名”：「一屏总览，全局在握」好过「仪表盘模块」。
- 痛点场景用对立词：各自 × 统一、手动 × 自动、慢 × 快。
- 收尾口号一句话，8–14 字，能独立成立。
- 观众读中文约 6–8 字/秒，一个场景的总字数 ≈ 场景秒数 × 5 为上限。

## 配乐要点

- 前奏（第一个 `big` 之前）不进鼓，留给 Logo 亮相；主歌段全编制；最后一个转场之后是尾声，撤鼓、铺底延音、淡出。
- `big` 选 3–5 个：开场亮相、主体出现（汇聚 / 第一次展示产品）、高潮段落、收尾。太多就不“重”了。
- `bright` / `warm` 的大节点用钟声而不是低频冲击，噪声类音效自动减弱，适合温和题材。
- 用户说“不要音乐”→ `mood: 'none'`；“只要音效”→ 仍用 `tech`，但可以把 BUS 混音里的 pad / lead 系数调低（`music.py` 的 `mixdown`）。
